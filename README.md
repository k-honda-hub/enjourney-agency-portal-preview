# Enjourney 旅行会社向けポータル — デザイン確認用デモ

採用済み v2.1 デザインを共同で確認・改善するための静的プレビューです。

## 操作

初期表示はテクノロジー。ノスタルジーにも切替できます。乗車地と期間を選択し、相談内容の入力・確認まで試せます。「この画面の接続状況」から合成サンプルを読み込めます。

## 未接続

実在庫、旅行会社ログイン、相談送信・予約確定、行程表添付、アカウントへの設定保存は未接続です。実際の個人情報や業務情報は入力しないでください。管理システム・データベース・認証情報はこのリポジトリに含みません。

## 共同制作

変更はブランチと Pull Request で提案してください。Issue には対象画面、PC/スマートフォン、期待する見た目・動作を記載してください。実データや秘密を投稿しないでください。main の更新は GitHub Pages のプレビューに反映されます。

## ローカル確認

Python がある環境では python -m http.server 8902 --bind 127.0.0.1 を実行し、http://127.0.0.1:8902/ を開きます。

初期表示では2026年11月の架空の空き状況を自動表示します。画面上部にも実在庫でないことを明記しています。PCでは標準倍率でカレンダーと相談ボタンを見渡せる密度に調整しています。
