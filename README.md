# Enjourney 旅行会社向けポータル — デザイン確認用デモ

採用済み v2.1 デザインを共同で確認・改善するための静的プレビューです。

## 操作

未設定時の初期表示はテクノロジー。ノスタルジーにも切替でき、最後の選択をこのブラウザに保存します。2026年11月の合成サンプルを最初から表示し、日付を2回押して期間を決め、相談内容の入力・確認まで試せます。「接続状況」からサンプルの再読込・未接続表示を切り替えられます。

## 未接続

実在庫、旅行会社ログイン、相談送信・予約確定、行程表添付、アカウントへの設定保存は未接続です。実際の個人情報や業務情報は入力しないでください。管理システム・データベース・認証情報はこのリポジトリに含みません。

## 共同制作

変更はブランチと Pull Request で提案してください。Issue には対象画面、PC/スマートフォン、期待する見た目・動作を記載してください。実データや秘密を投稿しないでください。main の更新は GitHub Pages のプレビューに反映されます。

## ローカル確認

Python がある環境では python -m http.server 8902 --bind 127.0.0.1 を実行し、http://127.0.0.1:8902/ を開きます。

## 採用デザインと画面サイズ

PCは採用画像の1536×1024の構図を基準に、文字・受付画像・カレンダーを同じ倍率で画面内へ収めます。画面の縦横比によって左右に余白ができます。「標準サイズで見る」で原寸に切替できます。1000px未満は通常の縦配置へ組み替え、スマートフォンへPC画面を縮小して押し込みません。入力・確認画面は読みやすい通常スクロールです。

赤と紺の装飾は文字を含まないSVG、見出し・日付・凡例・ボタン・入力欄はHTMLです。承認済みロボット素材と装飾用の富士山部分を使用しています。原画の筆文字・質感・ロボット素材の細部はピクセル同一ではありません。「今日」の日付はJST実日付で、未実装の「毎日更新」は表示しません。

画面下のデモ表示とスマートフォンのカレンダー上に、実在庫でないことを明記しています。条件や月を変更すると古いサンプルは「確認中」へ戻ります。送信成功や受付番号は生成しません。
